# 模型参数说明

不同功能和服务商提供的参数不完全相同。先填好服务商、密钥和模型，再按需要调整请求参数；默认值以当前界面为准，不要把一种功能的默认值套用到全部功能。

## Temperature（温度）

温度控制模型采样的随机性。较低值通常更稳定，较高值更有变化。

这是可选请求字段；未设置时使用服务端默认行为。是否支持以及接受的范围取决于模型。普通翻译、分析和创作不必使用相同温度。

## RPM（每分钟请求数限制）

RPM 控制请求速率，用于配合服务商限流。**0 表示本项不主动限制**，不代表服务商没有限制。

不同功能的默认值不同，例如当前高质量翻译默认为 7，不能统一理解成所有功能默认为 0。按账户实际限制调整。

## 每批次图片数

控制高质量翻译或校对一次发送多少图片。高质量翻译当前默认 3 张。

较大的批次可以提供更多上下文，也会增加输入体积和单次耗时。可先少量测试，再按漫画复杂程度调整。

## 强制 JSON 输出

请求服务商使用 JSON 格式返回。它有助于结构化解析，但不能保证语义正确，也不能保证任何服务都支持。

遇到不支持该请求字段的错误时，应按服务商文档调整。默认是否开启取决于具体功能。

## 流式调用

控制是否以流式方式接收模型响应。当前普通翻译和高质量翻译默认开启，AI 视觉 OCR 默认关闭。

流式接收不等于页面一定逐字显示全部模型输出；任务进度与译图仍按处理状态更新。它也不能替代解决服务端限流或连接错误。

## 重试次数

- **传输重试**：处理网络和部分 HTTP 错误。
- **业务重试**：处理模型结果解析或内容校验不符合要求等情况。

两者含义不同，调大重试次数可能增加等待与调用成本。任务中心的失败重试又是另一层操作，详情见[任务中心](/use/task-center)。

## 附加请求字段

需要服务商专用参数时，在对应的**附加请求字段（JSON 对象）**中填写，键名和值按服务商文档。

这里只接受 JSON 对象，不能是数组或普通文本。模型、消息、温度、流式等已有专用字段不能在此重复覆盖。

旧教程的统一“取消思考”开关和“会话重置频率”不对应当前 HQ / 校对表单。思考相关参数应以所选服务支持的附加字段为准，不要照搬其他模型的写法。

## 并行参数

“设置 → 更多”的并行参数控制任务处理资源，与模型 RPM 不同。增加并行不一定更快，还受 CPU、显存、模型服务和队列状态影响。

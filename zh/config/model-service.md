# 模型服务配置

翻译、AI 视觉 OCR、分析和生图需要配置对应的模型服务。您可以先配置准备使用的功能，不必一次填满所有页面。

## 翻译服务配置

在翻译页顶部点击**设置**。当前分类如下：

![新版设置分类与 OCR 配置](/images/v2-settings-ocr.png)

| 页签 | 配置内容 |
|------|----------|
| OCR识别 | 本地 OCR、百度 OCR、AI 视觉 OCR 与混合 OCR |
| 翻译服务 | 普通翻译的服务商、密钥、模型和请求参数 |
| 检测设置 | 检测器、辅助检测、掩膜和框扩展 |
| 高质量翻译 | 多模态模型、每批图片数和提示词 |
| AI校对 | 每轮模型、请求参数和提示词 |
| 提示词管理 | 管理可复用提示词 |
| 插件管理 | Python 流程插件及 Plugin Agent |
| 浏览器插件 | 插件文本样式与可选网页识别助手 |
| 文本默认值 | 新内容使用的初始文字样式 |
| 更多 | 并行、导出文件名、自定义服务、修复、字体等选项 |

### 服务商、密钥与地址

1. 选择服务商。
2. 填写对应 API Key；本地服务是否需要密钥，以该服务和界面要求为准。
3. 获取或输入该服务实际支持的模型名称。
4. 使用连接测试确认配置，再用少量图片验证效果。

内置云服务商使用预设地址，无需另填 Base URL。选择**自定义 OpenAI**时，才填写自定义兼容接口地址；Ollama、Sakura 等本地服务按其专用字段配置。

模型名称必须是接口接受的 ID，不一定等于产品展示名称。密钥获取见[如何获取 API Key](/config/get-api-key)。

### 自动保存与生效范围

设置修改后自动保存。失败时会显示错误，应先重试或处理冲突，不要把失败提示当作已经保存。

新任务使用创建时的配置。已经入队的任务不会因为您更换服务商而自动改用另一套参数；需要使用新配置时，请重新创建任务。

### 三种文字设置不要混淆

| 位置 | 作用 |
|------|------|
| 设置 → 文本默认值 | 新内容的初始字体、排版、颜色等 |
| 翻译左侧文字设置 / 编辑面板 | 当前工作内容和气泡样式；批量修改通过“应用到全部” |
| 设置 → 浏览器插件 | 插件专用文本样式，不改变 Web 的文本默认值 |

浏览器悬浮窗的 OCR、翻译服务、检测与高质量翻译直接共用 Web 对应配置；插件文本样式则与 Web 的“浏览器插件”页签共享。不是再维护一套独立翻译服务。

## OCR 与修复怎么选

本地选项包括 MangaOCR、PP-OCRv6 Medium、PaddleOCR-VL 1.6 和 48px OCR，也可使用百度 OCR 或 AI 视觉 OCR。根据语言与实际识别效果选择，使用本地模型前确认文件已准备好。

气泡填充支持纯色、LAMA-MPE、LiteLAMA 和 LaMa Manga。“更多 → LAMA 修复设置”可控制分区域高质量修复和自动缩放；这些选项会影响耗时与资源占用。详情见[编辑模式](/use/edit-mode)。

## 自定义服务复用

“更多 → 自定义 OpenAI 服务”可管理在多个功能中复用的地址、密钥和模型。选择预设服务时不需要把它改成自定义地址。

## 分析服务配置

分析页有自己的设置入口，分别配置视觉分析、对话、向量、重排序和生图功能。分析服务与普通翻译服务用途不同，不应假设只填翻译服务就能运行所有分析功能。

- 图片分析使用支持图片输入的模型。
- 智能问答按所选模式使用分析结果和检索配置。
- 续写生图还需要生图服务。
- 重排序是检索增强选项，不是翻译模型。

具体步骤见[漫画分析](/use/manga-insight)。请求参数解释见[模型参数说明](/config/model-params)。

## 本地版与公共部署

本文主要面向本地版。公共部署要求登录，功能、额度和部分选项可能由管理员控制，流程插件、网页导入或本地服务不一定开放。请以当前部署实际提供的入口为准。

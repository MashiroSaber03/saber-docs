# 常见问题解答 (FAQ)

Saber Translator 的常见问题解答页面。在寻求帮助之前，建议先在这里查找是否已经有对应答案。

---

## 一、安装与运行

### Q1: 我应该下载哪个文件？整合包和源代码有什么区别？

**A1:**

- **源代码（Source code）**：更适合愿意自己配置环境的用户
  - 优点：更新更快、占用空间更小、可自定义程度更高
  - 要求：需要自行安装 Python、依赖和相关模型
- **整合包**：更适合普通用户
  - 优点：解压即可使用
  - 缺点：更新通常需要重新下载完整包

### Q2: 双击程序后打不开 Web 页面怎么办？

**A2:** 先看桌面控制中心是否打开、后端是否已经启动。当前版本需要启动后端后才能访问 Web 页面。端口占用、依赖或模型缺失都可能导致启动失败，请查看**运行日志**中的具体错误。

不要仅根据闪退或打不开页面就断定是中文路径问题。实际日志位置见[数据管理](/use/data-management)。

### Q3: 启动很慢，正常吗？

**A3:** 模型首次使用或设为常驻时需要加载，等待时间取决于硬件和所选模型。桌面窗口打开、后端启动和首次模型调用是不同阶段；可通过运行日志判断当前在做什么。

## 二、基本功能

### Q4: 源语言选择英文、韩文等非日文语言时无法翻译，翻译结束后图片中没有嵌入任何文字

**A4:** 先查看检测框和 OCR 原文。确认所选 OCR 引擎支持目标语言、模型文件完整，再查看任务错误。若原文已识别但没有译文，继续检查翻译步骤；不要把所有无字结果都归因于路径。

### Q5: 开始翻译后报错“缺少必要的参数”

**A5:** 这通常表示模型配置没有填完整。请先参考[模型服务配置](/config/model-service)，把当前要使用的服务商、API Key 和模型名称填写完整。

### Q6: 报错 “AuthenticationError / Invalid token / 401 / BadRequestError” 一类错误

**A6:** 一般优先检查：

1. API Key 是否填错
2. 模型名称是否与当前服务商匹配
3. 自定义 Base URL 是否填错

例如：

- 选择 DeepSeek 服务商时，应填写 DeepSeek 自己支持的模型名
- 选择 SiliconFlow 服务商时，应填写 SiliconFlow 侧的模型名

### Q7: 翻译完成后除了译文，还出现了很多模型思考过程

**A7:** 这通常说明您使用了推理模型，或者没有正确关闭相关思考输出。最稳妥的做法是改用更适合翻译的非推理模型。

### Q8: 在图片之间快速来回切换后，主图和缩略图不一致，或者把某一张图的翻译嵌到了另一张图上

**A8:** 当前版本按页面保存并读取文档和图片结果，快速切换不应导致结果串页。若仍发生，请记录版本、页码、原图/译图状态和复现步骤，并附任务错误或日志反馈；不要将限制切图速度作为正常使用要求。

### Q9: 使用 AI 视觉 OCR、高质量翻译或 AI 校对时报错 “The model is not a VLM”

**A9:** 这说明当前模型不支持图片输入。AI 视觉 OCR、[高质量翻译](/use/hq-translation)、[AI 校对](/use/ai-proofreading)都需要使用支持视觉能力的[多模态模型](/config/model-types)。

### Q10: 高质量翻译和 AI 校对时报错 “thinking is not supported by this model...”

**A10:** 这说明当前模型不支持“取消思考”或相关 Thinking 参数。请检查对应服务的附加请求字段，按模型文档移除或修正不支持的参数。

### Q11: 支持哪些图片格式？可以处理整个文件夹吗？

**A11:** 支持常见图片和图片文件夹，以及 PDF、ZIP、CBZ、MOBI、AZW、AZW3。容器文件会创建后端导入任务。详见[内容导入与导出](/use/import-export)。

### Q12: 为什么翻译结果不准确或不通顺？

**A12:** 建议按这个顺序排查：

1. **OCR 是否识别正确**
2. **检测框是否合理**
3. **模型是否适合当前任务**
4. **提示词和术语约束是否合适**

如果是重要作品，推荐：

- 先整理[术语表/禁翻表](/use/glossary-non-translate)
- 再尝试[高质量翻译](/use/hq-translation)
- 最后用[AI 校对](/use/ai-proofreading)继续打磨

### Q13: 如何保存我翻译好的图片？

**A13:** 常见方式有两种：

- **单张保存**：点击“下载当前页”。
- **批量导出**：选择格式后点击“下载全部”，在任务中心查看导出任务。

### Q14: 什么是“仅消除文字”功能？它和翻译有什么区别？

**A14:** 默认执行检测与背景修复，发布无字图，跳过翻译。只有在“设置 → 更多”开启“同时执行OCR识别”后才额外进行 OCR，适合后续参考原文。

### Q15: 新版还需要保存会话吗？

**A15:** 新版将图片、气泡文档、结果与任务保存在后端，无需点击旧版“保存会话”按钮。不要把模型对话上下文与书籍数据保存混为一谈。

### Q16: 快速翻译模式和书架模式有什么区别？

**A16:** 两者都保存到后端。快速翻译使用固定工作区，便于直接导入；书架按作品和章节组织，适合长期管理。快速翻译可使用“保存到书架”整理为正式项目；“新建快速翻译”会重置工作区。

### Q17: 术语表和禁翻表在哪里？

**A17:** 在翻译页左侧“书籍约束”区域。当前快速翻译工作区也有对应约束，书架章节则按所属书籍共享。具体用法见[术语表/禁翻表](/use/glossary-non-translate)。

### Q18: 高质量翻译模式和 AI 校对模式分别适合什么时候用？

**A18:**

- **[高质量翻译模式](/use/hq-translation)**：适合做高质量初稿，尤其适合复杂场景、多角色对话和需要结合画面理解的页面
- **[AI 校对模式](/use/ai-proofreading)**：适合在已有译文基础上继续润色、纠错和统一风格

简单理解：

- 没有初稿时先用高质量翻译
- 已有初稿但还想继续打磨时用 AI 校对

### Q19: 我可以把翻译文本导出去用别的软件校对吗？

**A19:** 可以。程序支持导出和导入结构化翻译文本。您可以把文本整理后再导回，让当前图片重新使用更新后的译文。

## 三、配置与扩展

### Q20: 我可以在哪里获取 API Key？

**A20:** 您需要前往对应服务商官网注册并创建 API Key。详细步骤请参考[如何获取 API Key](/config/get-api-key)。

### Q21: 我想用自己的字体，怎么办？

**A21:** 在文字设置中的字体选择区域，可上传本地字体文件（如 `.ttf`、`.ttc`、`.otf`）。上传成功后即可在字体列表中使用。

### Q22: 插件系统在哪里打开？

**A22:** 插件系统入口在翻译页顶部的**设置**窗口中，进入“**插件管理**”页签即可看到插件列表、启用禁用、刷新、配置、导入导出等功能。详细说明请参考[插件系统](/use/plugin-system)。

### Q23: 自动生成插件前需要先做什么准备？

**A23:** 建议至少先准备好以下内容：

1. 明确您想让插件做什么
2. 在插件管理中打开“自动生成插件”
3. 先配置好**插件 Agent**所需的模型服务
4. 生成后检查发布的 v3 插件，启用并新建任务测试

如果只是普通用户，不需要一次把需求写得特别复杂，先从简单插件开始更稳。

## 四、故障排除

### Q24: 翻译失败时应该先检查什么？

**A24:** 优先检查：

1. API Key 是否正确
2. 模型名称是否与服务商匹配
3. 当前模型是否具备对应能力
4. 网络或额度是否正常

### Q25: 检测不到气泡怎么办？

**A25:** 建议按顺序尝试：

1. 切换检测器
2. 调整检测阈值
3. 开启辅助 YSGYolo 检测
4. 开启 SaberYOLO 二阶段纠错
5. 在[编辑模式](/use/edit-mode)中手动补框

### Q26: LAMA 修复效果不好怎么办？

**A26:** 可以尝试：

1. 检查检测框与精确文字掩膜相关参数
2. 调整掩膜膨胀大小
3. 在编辑模式中使用“修复”按钮重做局部区域
4. 使用修复笔刷和还原笔刷手动微调
5. 按需要尝试 LiteLAMA、LaMa Manga 或“更多”中的分区域高质量修复

### Q27: 文字显示不全怎么办？

**A27:** 常见处理方式：

1. 减小字号
2. 调整排版方向
3. 扩大气泡框
4. 调整文本框扩展参数

## 五、数据管理

### Q28: 如何保存翻译进度？

**A28:** 快速翻译和书架章节的结果都由后端保存。编辑退出前会等待当前文档保存；若提示失败，应先处理错误。无需再寻找旧版保存进度按钮。

### Q29: 如何迁移数据？

**A29:** 兼容版本之间可停止后端后复制完整实际数据目录。旧版 `data` 不能直接转换为新版 `data-v2`，请参考[数据保存与备份](/use/data-management)。

### Q30: 如何备份数据？

**A30:** 停止后端并退出程序，备份整个实际数据目录。源码默认在项目 `data-v2`；Windows 整合包默认在 `%LOCALAPPDATA%\SaberTranslator\data-v2`。指定过数据目录时使用指定位置。

## 六、其他问题

### Q31: 如何更新版本？

**A31:** 先备份实际数据目录，再更新程序和对应依赖、模型。遇到数据结构不兼容提示时先保留备份，不要直接覆盖或删除数据库。步骤见[Windows 部署](/deploy/saber/windows)。

### Q32: 漫画续写为什么提示缺少分析数据，无法直接开始？

**A32:** 因为[漫画续写](/use/manga-continuation)依赖已有分析结果来理解原作剧情、角色关系和故事上下文。通常需要先完成足够完整的漫画分析，必要时还要补齐续写所需的生图模型配置。

### Q33: 角色工坊和漫画分析里的角色摘要有什么区别？

**A33:** 漫画分析里的角色摘要更偏“看结果”，而[角色工坊](/use/character-studio)更偏“做资料”。角色工坊适合把角色整理成可编辑、可导出、可长期维护的角色文档。

### Q34: 如何提交问题反馈？

**A34:** 建议在 [GitHub Issues](https://github.com/MashiroSaber03/Saber-Translator/issues) 提交，并尽量附上：

1. 操作系统和版本信息
2. 错误截图或日志
3. 复现步骤
4. 当前使用的服务商、模型和相关配置


### Q35: 关闭浏览器后任务还会运行吗？

**A35:** 翻译器 Web 页面提交的后台任务会继续；浏览器插件漫画页退出后则会取消并清理临时会话。两者不同，详见[任务中心](/use/task-center)。

### Q36: 插件配置和翻译器设置是否共享？

**A36:** 悬浮窗中的 OCR、翻译服务、检测、高质量翻译读写 Web 对应设置。插件文本样式与“设置 → 浏览器插件”共享，但不修改“文本默认值”。详情见[浏览器插件](/use/browser-extension)。

### Q37: 描边宽度可以输入小数吗？

**A37:** 可以，保留小数输入；点击增减箭头或使用方向键时，步长为 1。

### Q38: 局域网访问提示 crypto.randomUUID is not a function 怎么办？

**A38:** 当前版本已处理普通 HTTP 局域网环境的兼容问题。请确认运行的是新版后端及其配套 Web 构建，刷新页面后再试；若仍报错，附版本、访问地址类型和日志反馈。

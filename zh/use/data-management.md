# 数据保存、备份与更新

新版 Saber Translator 将导入内容、编辑结果和任务记录保存在后端。理解保存位置，可以避免更新软件时遗漏数据。

## 哪些内容会保存

| 内容 | 保存方式 |
|------|----------|
| Web 快速翻译 | 后端固定工作区，重新打开可继续；“新建快速翻译”会重置该工作区 |
| 书架书籍与章节 | 导入和处理结果写入后端，进入章节后读取已有数据 |
| 编辑文档 | 编辑操作提交后保存；退出编辑前等待当前文档保存 |
| 翻译与分析任务 | 后端记录状态和结果，关闭 Web 页面不等于取消任务 |
| 浏览器插件漫画页 | 临时会话，退出漫画页面后取消并清理；主动导入书架的内容保留 |

::: tip 两种“页面退出”不同
关闭翻译器 Web 页面，已提交的后台任务可以继续；关闭使用浏览器插件的漫画页面，则会清理该页面的临时任务。详情见[浏览器插件](/use/browser-extension)。
:::

自动保存不代表尚未成功上传、提交失败或还在编辑中的内容已经落盘。遇到保存失败提示，应先处理错误，再关闭页面。

## 数据在哪里

| 运行方式 | 默认数据目录 |
|----------|--------------|
| 从源码启动 | 项目根目录下的 `data-v2` |
| Windows 整合包 | `%LOCALAPPDATA%\SaberTranslator\data-v2` |
| 显式指定目录 | `--data-dir` 指定的目录，或环境变量 `SABER_V2_DATA_ROOT` |

指定目录会覆盖默认位置，应以当前启动参数和实际使用的数据目录为准。

| 文件或目录 | 作用 |
|------------|------|
| `saber.sqlite3` | 书籍、章节、页面、设置、任务等业务数据 |
| `objects/` | 原图、译图、缩略图及其他资产 |
| `plugins/` | 已导入的流程插件版本 |
| `chroma/` | 分析检索相关的向量数据 |
| `launcher-settings.json` | 桌面启动、模型常驻、扩展连接等设置 |
| `logs/` | 运行日志 |

这些内容相互关联，不建议只复制数据库或只复制图片目录。

## 如何备份

1. 等待需要保留的操作提交完成。
2. 停止后端并退出桌面程序，确保该目录没有进程继续写入。
3. 将整个实际数据目录复制到另一处，保留原目录结构。
4. 记录备份对应的程序版本。

模型文件不包含在上述默认数据目录中：源码版位于项目的 `models/`，当前 Windows 整合包位于程序目录的 `_internal/models/`。自行添加的模型也应另行保管。

## 如何恢复或换电脑

使用与备份数据结构兼容的程序版本，把完整备份放到目标数据目录后再启动。也可以通过 `--data-dir` 指向恢复后的目录。

::: warning 旧版迁移
重构前的 `data/bookshelf`、`data/sessions` 与新版 `data-v2` 不是同一种存储格式。复制旧目录不会自动转换。当前程序不会自动迁移旧业务数据；请保留旧程序和完整备份，按对应版本的迁移说明处理，或从旧版导出可用文件后重新导入。
:::

若提示数据结构版本不兼容，先保留完整备份，再决定使用兼容版本还是另建新数据目录。不要直接覆盖数据库或删除旧目录。

## 导出与备份有什么区别

图片、PDF、CBZ 或翻译文本导出适合阅读和交付；完整数据目录备份用于保留可继续编辑的项目、设置和任务记录。导出的译图不能替代整个项目的备份。

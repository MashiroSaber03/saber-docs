# 桌面控制中心

桌面控制中心负责启动本机后端、查看运行状态和管理基础设置。漫画翻译、阅读与分析的工作区仍在 Web 页面中。

## 启动与停止

1. 打开程序，进入桌面控制中心。
2. 点击**启动后端**。
3. 等待后端就绪，再打开 Web 页面。
4. 结束使用时，通过控制中心停止后端。

仅关闭 Web 标签页不会停止后端。停止后端会影响正在执行的任务；重新启动后应在[任务中心](/use/task-center)检查状态，按可用操作继续处理。

## 主要页面

| 页面 | 作用 |
|------|------|
| 概览 | 查看后端状态，启动、停止并打开 Web 页面 |
| 任务中心 | 查看同一后端队列中的任务，进行暂停、恢复、取消等操作 |
| 运行日志 | 按来源、级别筛选日志，复制错误信息 |
| 设置 | 修改端口、局域网访问、模型常驻、扩展连接和桌宠等选项 |

## 基础设置

- **端口**：默认 5000。修改后连接地址和扩展中的端口也需要对应调整。
- **局域网访问**：需要从手机或另一台设备访问本机时开启。
- **自动打开浏览器**：控制后端启动后是否自动打开 Web 页面。
- **日志级别**：调整显示的日志详细程度。

运行相关设置按界面提示重启后端后生效。

## 模型常驻

常驻模型会提前加载并保持在 Worker 中，可以减少后续首次调用的等待，但会占用内存或显存。

未设为常驻不代表不能使用该模型。普通用户可先保持默认，只把经常使用且资源足够的模型设为常驻。

## 浏览器扩展连接

使用[浏览器插件](/use/browser-extension)前，在这里开启**允许浏览器扩展连接**，复制配对令牌，然后在普通网页点击浏览器工具栏的 Saber 图标，在悬浮窗**配置 → 连接与站点**中填写令牌和端口。

不再使用时可关闭连接；重新生成令牌后，旧令牌失效，需要重新配对。

## 桌宠

桌宠用于显示运行状态，可在设置中调整显示、置顶和大小。关闭桌宠不等于停止后端。

## 出现问题时

先确认后端是否启动，再到**运行日志**查看相应时间的错误。反馈时提供版本、操作步骤、任务错误与日志片段，避免附带 API Key 或配对令牌。

数据位置与备份方法见[数据保存、备份与更新](/use/data-management)。

# 任务中心

任务中心用于查看后台正在做什么，以及处理暂停、中断或失败的任务。桌面控制中心、翻译器 Web 页面和浏览器插件连接同一后端时，操作的是同一套任务。

## 在哪里打开

![当前 Web 任务中心队列界面](/images/v2-task-center.png)

- **桌面程序**：进入左侧“任务中心”。
- **Web 页面**：点击任务中心入口。
- **浏览器插件**：打开漫画页悬浮窗，切换到“任务”。

## 任务状态与操作

队列页查看当前和等待中的任务；历史页可按状态、类型和书籍筛选。详情用于定位具体步骤与错误。Web 界面还提供批量分析和释放显存入口，按需要使用。

可用按钮随任务类型和状态变化，以界面实际显示为准。

| 操作 | 作用 |
|------|------|
| 暂停 | 请求任务在可暂停的位置停下，不一定立即中断正在执行的模型调用 |
| 恢复 | 继续已暂停的任务 |
| 继续中断任务 | 对可恢复的中断任务继续执行 |
| 取消 | 请求停止任务，不等于删除已导入的书籍 |
| 失败重试 | 重试允许重新执行的失败任务 |
| 暂停 / 恢复全局队列 | 控制同一后端队列的调度，会影响其他页面提交的任务 |

## 关闭页面后会怎样

Web 页面只是查看与操作入口，已提交的翻译、分析、导入、导出任务由后端执行。关闭或刷新 Web 页面后，可以重新打开任务中心查看。

::: warning 浏览器插件的例外
网页漫画插件采用临时会话。关闭或离开漫画页面时，会取消并清理该页面的临时任务。要保留结果，应先导入书架。
:::

停止程序、断电或进程崩溃不等于任务正常完成。重新启动后，查看任务状态，再使用界面提供的恢复或重试操作。

## 修改配置后如何生效

任务创建时会记录它使用的配置和流程插件版本。后续修改设置，不会把已经入队的任务自动改成新配置。

- 希望继续暂停或中断的原任务：使用恢复或继续，保留原任务配置。
- 希望使用当前设置重试：Web 的“重试任务 / 重试失败项”对支持的任务类型按当前设置创建新任务。
- 希望重试仍使用旧配置：选择“沿用原快照”。
- 样式批量应用等不支持重取当前设置的类型仍沿用原快照，以实际可用操作为准。
- 浏览器插件已有结果：使用“按新配置重新翻译”，替换当前临时会话。

重试会创建关联原任务的新任务，不等于在原任务上直接覆盖配置。浏览器插件漫画会话另有固定配置范围，详见[浏览器插件](/use/browser-extension)。

## 如何排查失败

1. 打开失败任务的详情，查看失败步骤和错误信息。
2. 判断是文件导入、OCR、模型服务还是渲染阶段的问题。
3. 修正原因后，根据需要重试或重新创建任务。
4. 如需反馈，记录任务错误和运行日志。

队列暂停、任务暂停和模型请求耗时较长是不同情况；不要仅凭进度暂时不动就反复点击启动。

# 浏览器插件

浏览器插件用于直接翻译网页上的漫画图片，并在原位置查看译图。当前支持桌面版 Chrome 和 Edge，需要本机 Saber Translator 后端运行。

它与“设置 → 插件管理”中的 Python 流程插件不同；流程插件说明见[插件系统](/use/plugin-system)。

## 安装与配对

### 商店安装（推荐）

使用对应浏览器打开商店页面，点击添加扩展即可，无需开启开发者模式：

- [Edge 浏览器插件](https://microsoftedge.microsoft.com/addons/detail/saber-%E6%BC%AB%E7%94%BB%E7%BF%BB%E8%AF%91/obhjpabpgnenlgcakbiaoekdjfjfcmbm)
- [Chrome 浏览器插件](https://chromewebstore.google.com/detail/saber-%E6%BC%AB%E7%94%BB%E7%BF%BB%E8%AF%91/eocjphcpiagifkhfigoekaemdbbfdcjl)

### 手动安装 ZIP

1. 下载与当前程序配套的浏览器扩展 ZIP，完整解压。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启开发者模式，点击**加载已解压的扩展程序**，选择直接包含 `manifest.json` 的目录。

ZIP 不能直接当作已解压目录加载。

### 连接本机 Saber

两种安装方式都需要完成配对：

1. 在[桌面控制中心](/use/desktop)启用**允许浏览器扩展连接**，复制配对令牌，并启动后端、等待就绪。
2. 打开普通网页，点击浏览器工具栏的 Saber 图标，打开网页悬浮窗。
3. 在**配置 → 连接与站点**中填写令牌和本机端口，点击**保存并连接**。首次未配对时会直接进入连接设置。

工具栏图标与网页悬浮按钮打开同一个悬浮窗，翻译、配置和任务操作均在其中完成。浏览器内置页等受限页面不支持注入，请在普通网页中操作。

## 翻译网页漫画

![浏览器悬浮窗在测试网页中的实际界面](/images/v2-browser-floating.png)

上图使用测试图片演示悬浮窗，实际使用时显示当前漫画及其翻译结果。

1. 打开漫画页面，点击粉色悬浮按钮。
2. 选择识别方式，检查候选图片并选择需要翻译的页面。
3. 确认开始，插件才会上传所选图片。
4. 在悬浮窗中查看进度，译图完成后会逐张替换到网页原位置。

也可以右键单张图片，选择**使用 Saber 翻译此图片**。

### 识别方式

| 方式 | 适合的情况 |
|------|------------|
| 站点适配 / 通用 | 优先尝试；已适配站点使用规则，其他站点按图片和页面结构筛选 |
| 点选同类图片 | 自动识别不合适时，点一张漫画图找出同类图片 |
| DOM Agent | 使用网页识别助手分析图片节点摘要，结果仍需人工确认 |

网页识别助手只参与图片识别，不负责漫画翻译。未配置时，也可以使用前两种方式。

确认后，新出现并符合规则的懒加载图片会继续加入。**停止继续发现**只停止加入新图片；**取消任务**用于停止当前处理。

### 查看与重新翻译

- 全局或逐页切换原图 / 译图。
- 对单页进行重翻或失败重试。
- 当前任务结束或取消后，用**按新配置重新翻译**重新处理当前图片。

新配置重翻会替换临时结果，已导入书架的内容不受影响。悬浮窗启动前会等待配置保存；保存失败时先回到配置页处理。

## 在悬浮窗中配置

进入**配置 → 配置分类**：

| 配置 | 与 Web 页的关系 |
|------|----------------|
| OCR 识别 | 与翻译页“设置 → OCR识别”共用 |
| 翻译服务 | 与翻译页对应设置共用 |
| 检测设置 | 与翻译页对应设置共用 |
| 高质量翻译 | 与翻译页对应设置共用 |
| 插件文本样式 | 与“设置 → 浏览器插件”共用，独立于“文本默认值” |
| 网页识别助手 | 浏览器插件专用，只供 DOM Agent 使用 |

修改后自动保存，无需另点保存按钮。内置服务商使用预设地址；自定义 OpenAI 服务才需要配置自定义地址。

重新进入配置时读取已保存的新值；未保存或保存失败的草稿不会被刷新覆盖。多个窗口同时修改发生冲突时，应先处理提示，再继续。

同一临时会话的后续页面与重试沿用该会话的配置。修改配置后，要让已有漫画按新配置处理，请使用**按新配置重新翻译**。

## 任务中心

切换到悬浮窗的**任务**页签即可查看与操作同一后端队列，不需要另开翻译器页面。操作含义见[任务中心](/use/task-center)。

## 保留结果与退出

需要长期保存时，使用**导入到书架**，新建一本书或追加到已有书籍。

| 操作 | 临时任务与数据 |
|------|----------------|
| 收起悬浮窗、切换标签页、窗口失焦 | 保留 |
| 刷新、关闭标签页、离开当前漫画页面 | 取消并清理，重新打开不恢复 |
| 主动导入书架 | 已导入内容长期保留 |

浏览器异常退出时，后端会在页面存活租约失效后清理；清理需要等待运行中的任务释放图片，不一定瞬间完成。

## 位置与站点设置

悬浮按钮和面板标题栏均可拖动。每次展开时，面板贴近悬浮按钮并避开窗口边缘；手动拖动面板只影响本次展开。

站点不需要使用插件时，可停用该域名。要重新启用，点击浏览器工具栏的 Saber 图标，在悬浮窗**配置 → 连接与站点**中操作。站点结构变动导致识别异常时，可在**翻译 → 页面操作**删除已保存适配，再重新识别。

## 更新与常见问题

- **商店安装版**：更新由浏览器管理，也可点击悬浮窗顶部版本号手动检查更新；发现待安装新版后会提示，可在完成当前阅读后重启浏览器。
- **手动 ZIP 安装版**：更新时先关闭漫画页，将新包覆盖到原扩展目录，再在浏览器扩展管理页重新加载。使用同一目录可保留配对和域名设置；换目录重新安装可能需要重新配对。开发者模式安装不提供商店更新检查入口。

连接失败时，检查后端、扩展连接开关、令牌和端口是否一致。令牌重新生成后需重新配对。

需要登录或验证的网站，应先在当前页面完成验证。跨域 iframe、受保护资源或浏览器禁止读取的 Canvas 不保证可用；条漫切片不会自动拼接成一张图。

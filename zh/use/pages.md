# 页面介绍

Saber Translator 的 Web 界面主要由四个核心页面组成，每个页面专注于不同的功能。

## 书架页面

书架页面是您管理漫画项目的中心。也是Saber Translator各个功能页面的入口。

![image-20251220024130562](/images/bookshelf-display.png)

### 主要功能

- **项目列表**：以卡片形式展示所有漫画项目，显示封面、标题和进度
- **创建项目**：点击"新建书籍"按钮创建新的翻译项目
- **标签筛选**：通过标签对项目进行分类和筛选
- **搜索功能**：快速搜索定位特定项目
- **批量操作**：支持批量删除、批量添加标签等操作

### 项目卡片

每个项目卡片显示：
- 漫画封面图
- 项目标题
- 章节数量

点击项目卡片可进入章节列表，选择具体章节进行翻译。

## 翻译页面

![image-20251220024923130](/images/translation-display.png)

翻译页面是进行漫画翻译的主要工作区。

### 界面布局

| 区域 | 说明 |
|------|------|
| **右侧图片列表** | 显示当前章节的所有图片缩略图 |
| **中央预览区** | 大图预览，显示原图或翻译结果 |
| **左侧控制面板** | 翻译参数设置和操作按钮 |

### 控制面板功能

**翻译设置**
- 源语言 / 目标语言选择
- OCR 引擎选择（MangaOCR、PaddleOCR、百度OCR、AI视觉OCR）
- 翻译服务选择（支持多种 AI 服务商）
- 文字消除方式（LAMA 修复 / 纯色填充）

**渲染设置**
- 字体选择和字号
- 文字颜色和描边
- 排版方向（竖排/横排）

**操作按钮**
- [翻译当前图片 / 批量翻译](/use/normal-translation)
- [高质量翻译](/use/hq-translation)
- [AI校对](/use/ai-proofreading)
- 保存会话
- 进入[编辑模式](/use/edit-mode)

## 编辑页面

![image-20251220024747535](/images/edit-display.png)

编辑页面用于精细调整翻译结果。

### 界面布局

- **左侧**：原图预览（显示原文）
- **中央**：翻译图预览（显示翻译结果）
- **右侧**：属性编辑面板

### 顶部工具栏

- **检测/批量检测**：重新检测文本区域
- **翻译**：重新翻译当前气泡
- **添加**：手动添加新气泡
- **删除**：删除选中的气泡
- **修复/恢复笔刷**：手动修复背景
- **快捷键**：查看快捷键列表

### 右侧编辑面板

**文本编辑**
- **原文（OCR结果）**：显示识别的原文，可复制或重新识别
- **译文**：编辑翻译后的文本，支持多行

**样式设置**
- 字体选择和字号调整（A+/A- 快速调整）
- 排版方向切换（竖排/横排）
- 文字消除方式（LAMA修复）
- 文字颜色和描边设置
- 旋转角度和位置偏移调整

**操作按钮**
- **应用**：应用当前气泡的修改
- **应用全部**：将设置应用到所有气泡
- **重置**：重置当前气泡的修改

## 分析页面

![image-20251220025231066](/images/analysis-display.png)

分析页面提供基于 AI 的漫画内容分析功能。

### 主要区域

**分析控制区**
- 启动/暂停/继续分析任务
- 选择分析模式（全书/增量/章节/页面）
- 查看分析进度

**结果展示区**
- 故事概要和角色档案
- 剧情时间线
- 页面详细分析

**智能问答区**
- 基于分析结果的问答功能
- 支持精确检索和全局摘要两种模式
- 显示引用来源

### 数据导出

支持将分析结果导出为：
- JSON 格式（便于程序处理）
- Markdown 格式（便于阅读和分享）

详细使用方法请参考[漫画分析](/use/manga-insight)章节。

## 漫画续写页面

![image-20251220025231066](/images/manga-continuation.png)

漫画续写页面用于在已完成漫画分析的基础上继续创作后续剧情。它并不是直接一步生图，而是将续写流程拆分为多个阶段，方便您先确认故事方向，再逐步生成脚本、页面剧情和最终图片。

### 主要区域

- **步骤导航区**：显示当前续写所处的阶段，可在角色设置、生成脚本、页面剧情、图片生成/导出之间切换
- **续写设置区**：配置续写页数、画风参考页数和续写方向，决定本次续写的基本目标
- **角色管理区**：管理续写中会出场的角色和角色形态，为后续脚本和生图提供约束
- **脚本与页面剧情区**：先生成整话脚本，再拆分为逐页剧情，可逐页检查和手动修改
- **图片生成与导出区**：支持批量生成或单页重生续写图片，并可导出最终结果

### 主要功能

- 基于已完成的分析结果继续创作后续剧情
- 生成整话脚本并拆分为逐页剧情
- 使用参考图维持画风和角色表现的一致性
- 支持批量生成、单页重生和导出结果

详细使用方法请参考[漫画续写](/use/manga-continuation)章节。

## 角色工坊页面

![image-20251220025231066](/images/character-studio.png)

角色工坊页面是独立的角色资料工作台，用于把漫画分析得到的角色信息进一步整理为可编辑、可导出、可长期维护的角色文档。相比分析页中的角色摘要，角色工坊更强调长期整理和后续复用。

### 界面布局

- **顶部工具栏**：显示当前书籍和文档信息，提供返回、保存、校验、打开资源面板和导出入口
- **左侧编辑区**：用于编辑角色基础设定、问候语、世界书、正则脚本、状态任务等核心内容
- **右侧预览区**：用于聊天预览、提示词预览和卡片助手，便于检查角色表现是否符合预期

### 资源面板

角色工坊中的候选角色、已创建文档、搜索、手工创建和导入入口通常位于资源面板中。资源面板可单独打开，用于在不同角色文档之间切换，而不是常驻为第三列布局。

### 主要功能

- 从分析结果中挑选候选角色并创建角色文档
- 维护角色基础设定、问候语和世界书内容
- 支持生成、校验、导入导出和 worldbook 处理
- 支持聊天预览与卡片助手辅助完善角色资料

详细使用方法请参考[角色工坊](/use/character-studio)章节。

# 内容导入与导出

## 导入本地文件

翻译页上传区域支持多张图片、图片文件夹，以及 PDF、ZIP、CBZ、MOBI、AZW、AZW3。

- 图片上传成功后写入当前后端章节。
- PDF、压缩包和电子书创建后台导入任务。
- 图片上传部分失败时，可只重试失败项，已成功内容不会重复导入。
- 在确认提交成功前，不要把仍在上传的文件当作已经保存。

快速翻译使用固定工作区；希望按作品整理时，可点击**保存到书架**。已有书籍可从章节进入后再导入。

## 从网页导入漫画

![当前网页导入入口](/images/v2-web-import.png)

上传区域点击**从网页导入**：

1. 输入漫画网址。
2. 选择自动选择、Gallery-DL 或 AI Agent。
3. 提取后检查候选图片，选择需要的页面。
4. 确认导入，在[任务中心](/use/task-center)查看处理状态。

自动选择会根据网站支持情况决定使用的引擎。AI Agent 与相关服务需在导入窗口中配置；该窗口的设置按其保存按钮和提示提交，不要与翻译设置的自动保存混淆。

需要登录、验证或有站点限制的资源不保证可以导入。该功能将内容导入 Saber；如果想留在原网页看译图，请使用[浏览器插件](/use/browser-extension)。

## 图片导出

在翻译页的**导出与交换**区域：

- **下载当前页**：优先下载译图，没有译图时使用干净背景或原图。
- **下载全部**：选择 ZIP、PDF 或 CBZ，提交后台导出任务。
- 页面关闭后，导出任务继续，可从任务中心查看产物。

“设置 → 更多 → 下载设置”的**保持原文件名**控制是否添加结果类型前缀，文件扩展名仍与实际格式一致。

## 翻译文本交换

- **Saber JSON**：可导出并重新导入，用于外部修改译文后回填。
- **LabelPlus TXT**：用于外部嵌字工具，不是 Saber JSON 的替代导入格式。

导入 JSON 时先查看预览和冲突情况，再确认提交。当前文档已变化的页面可能被标为冲突，不能保证旧文件无条件覆盖最新修改。

## 书籍与章节批量导出

书架和章节管理中的导出也会提交后台任务。完成后获取产物；若显示部分失败，应查看错误并确认导出范围。

项目备份与图片交付不是一回事，完整备份方法见[数据保存与备份](/use/data-management)。

# 书架系统

书架页面负责把 Saber Translator 的主要功能串联起来。翻译、阅读、分析都以书架为正式入口；如果您准备长期维护某部作品，通常都建议先进入书架模式，而不是直接临时上传图片。

![](/images/bookshelf-display.png)

## 核心概念

### 层级结构

![image-20251220143015480](/images/book-details.png)

```text
书架
├── 书籍 1
│   ├── 章节 1
│   │   └── 图片 1, 2, 3...
│   ├── 章节 2
│   └── 章节 3
├── 书籍 2
└── 书籍 3
```

### 书籍

书籍是最顶层的组织单位：

- 代表一部完整的漫画作品
- 包含多个章节
- 可设置封面、标题、标签

### 章节

章节是书籍的子单位：

- 代表漫画的一话 / 一集
- 包含该章节的所有图片
- 关联独立的翻译会话和章节进度

## 书籍管理

### 创建书籍

![image-20251220143358406](/images/create-book.png)

1. 在书架页面点击“新建书籍”
2. 填写书籍信息：
   - **标题**：书籍名称（必填）
   - **封面**：上传封面图片（可选）
   - **标签**：添加分类标签（可选）
3. 点击“创建”完成

### 编辑书籍

1. 打开书籍详情
2. 点击对应编辑入口
3. 修改书籍信息并保存

### 删除书籍

1. 在书籍详情中点击删除
2. 确认删除操作

::: warning 注意
删除书籍会同时删除其下所有章节和翻译数据，此操作不可恢复。
:::

---

## 章节管理

### 创建章节

1. 打开书籍详情
2. 点击“添加章节”
3. 填写章节标题与顺序信息
4. 上传该章节图片

### 章节排序

调整章节顺序：

1. 点击“排序”按钮进入排序模式
2. 拖拽章节调整顺序
3. 点击“完成”保存

### 删除章节

1. 点击章节的“删除”按钮
2. 确认删除

## 进入翻译

### 从书架进入

![image-20251220143916034](/images/enter-translation.png)

1. 点击书籍卡片打开书籍详情
2. 在章节列表中选择要处理的章节
3. 点击“进入翻译”

### 书架模式的意义

从书架进入翻译页面后，当前章节会进入**书架模式**。相比直接上传图片的快速翻译模式，它的优势是：

- 自动绑定章节会话
- 支持保存和恢复翻译进度
- 支持[术语表/禁翻表](/use/glossary-non-translate)
- 更适合长篇、连载和正式项目

### 继续翻译

如果之前已经保存过进度：

1. 再次进入同一章节
2. 系统自动加载历史会话
3. 继续之前的翻译和编辑工作

## 进入阅读

### 阅读翻译结果

![image-20251220144644950](/images/enter-reading.png)

翻译完成后，可以通过书架进入阅读模式：

1. 点击书籍卡片
2. 在章节列表中选择已翻译的章节
3. 点击“进入阅读”

### 阅读模式功能

- 查看翻译后的漫画结果
- 在原图和译图之间切换
- 通过上下章导航连续阅读
- 适合竖向流式阅读
- 支持缩放查看细节
- 可复制局域网访问地址，方便在手机上阅读

---

## 进入分析

### 漫画分析入口

![image-20251220144731642](/images/enter-analysis.png)

从书架进入漫画分析功能：

1. 点击书籍卡片
2. 点击“漫画分析”

### 分析页能做什么

漫画分析页面不仅可以做内容分析，还可以继续进入后续工作：

- 对漫画内容进行深度分析
- 提取角色、情节等信息
- 生成故事概述和模板内容
- 对漫画情节进行智能问答
- 生成剧情时间线
- 进入**漫画续写**
- 进入**角色工坊**

详细使用方法请参考[漫画分析](/use/manga-insight)章节。

## 数据存储

### 存储位置

书架数据存储在项目目录下：

```text
data/
├── bookshelf/              # 书架数据目录
│   ├── books.json          # 书籍列表摘要（标题、封面、章节数等）
│   ├── tags.json           # 标签元数据
│   └── [book_id]/          # 单本书籍目录
│       ├── book_meta.json  # 书籍详细元数据
│       ├── cover.b64       # 封面图片（Base64）
│       └── chapters/       # 章节目录
│           └── [chapter_id]/
│               └── chapter_meta.json  # 章节元数据
└── sessions/
    └── bookshelf/          # 章节翻译会话数据
        └── [book_id]/
            └── [chapter_id]/
                ├── session_meta.json      # 会话元数据
                ├── image_0_original.png   # 原图
                ├── image_0_translated.png # 译图
                ├── image_0_clean.png      # 干净背景
                └── ...
```

### 数据说明

| 文件 | 说明 |
|------|------|
| `books.json` | 所有书籍的摘要信息，用于书架列表快速加载 |
| `book_meta.json` | 单本书的完整元数据（章节列表、标签、时间戳等） |
| `session_meta.json` | 章节的翻译会话数据（UI 设置、图片元数据等） |
| `image_*_*.png` | 实际图片文件 |

### 数据备份

建议定期备份 `data` 目录，以防数据丢失：

- 备份整个 `data` 目录即可保留所有书籍、章节和翻译数据
- 数据迁移时通常只需复制 `data` 目录

## 最佳实践

### 项目组织建议

1. **按作品创建书籍**：一部漫画对应一本书
2. **按话数创建章节**：每一话 / 每一集对应一个章节
3. **使用标签分类**：按类型、状态、优先级等整理
4. **正式项目尽量走书架模式**：便于保存、恢复和长期维护

### 命名规范

| 类型 | 建议格式 | 示例 |
|------|----------|------|
| 书籍标题 | 作品名称 | 咒术回战 |
| 章节标题 | 第 X 话 / 集 | 第 1 话 |
| 标签 | 分类名 | 少年漫画、进行中 |
